# Korvath — Object, Weapon & Relic Consistency Bible

This document anchors non-human entities (swords, sorcerous artifacts, ancient monoliths) to prevent visual drift between panels.

---

## 🎯 Protocol: Object On-Boarding (3-Step Mandate)

Whenever a signature weapon, relic, or vehicle/beast is introduced:
1. **Define Object DNA Formula:** Geometry, surface materials, and 3 non-negotiable silhouette markers.
2. **Generate 3-View Object Model Sheet:** `npm run sheet:object <key>` (Side Profile, Perspective, Action).
3. **Register in `object_prompts.json`:** Single-anchor prompt string.

* **Entity Type:** Melee Weapon / Signature Broadsword
